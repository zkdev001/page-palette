# Page Palette

Customize website colors for more comfortable reading.

## Installation

1. Download and extract the ZIP.
2. Open `brave://extensions` and enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the `page-palette` folder containing `manifest.json`.

Keep this folder on your computer while using the extension.

## Usage

1. Open a website and click the Page Palette extension.
2. Click **Enable on this site** and approve site access.
3. Choose your background and text colors, or select a quick theme.

Use **Save as default** to reuse your preferred colors on other sites.

## Custom Elements

1. Expand **Custom Elements** and click **Pick an element**.
2. Click an element on the page.
3. Use **Select larger area** to select its surrounding container.
4. Check the colors you want to change, choose colors, and click **Save**.

**Cancel** or **Escape** discards the preview.

Manage saved elements under **Custom Elements** to edit colors, highlight, disable, or delete them. Entries are grouped by site and apply to the page where they were saved.

## Run Locally

Settings stay in your browser. No data is sent to external services. Page access is granted only for sites you enable.
